# tools

JMicron mass production and firmware update utilities.

> **Languages:** English · [简体中文](README.cn.md)

## Contents

| Subdirectory | Tool | Use |
| --- | --- | --- |
| [`FwUpdateTool/`](FwUpdateTool/) | JM2033x FW Update Utility (`FwUpdateTool_v1_19_16_24.exe`) | Simple single-chip firmware update (JMS578, JMS565 Series identification, …) |
| [`JMMassProd/`](JMMassProd/) | JMicron 2033x M.P. Tool (`JMMassProd2_v1_16_14_1.exe`) | Full mass production: firmware update, EEPROM (VID/PID, strings, standby timer, serial), partition / format / read-write tests |

Each subdirectory has its own README with English and Chinese versions.
